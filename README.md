# 🏥 Hospital Readmit Risk Prediction

An AI/ML-based project designed to predict the risk of hospital readmission using patient-related healthcare data.

## 📌 Project Overview

Hospital Readmit Risk Prediction uses machine learning and healthcare data to estimate the likelihood of a patient being readmitted to a hospital.

The project combines a Python-based backend with a modern web frontend to provide an interactive prediction experience.

## ✨ Features

- Hospital readmission risk prediction
- Machine learning-based prediction model
- Patient data processing and preprocessing
- RAG-based retrieval functionality
- Interactive web dashboard
- Prediction history
- Model status monitoring

## 🛠️ Technologies Used

**Backend**
- Python
- Machine Learning
- XGBoost
- FAISS
- Jupyter Notebook

**Frontend**
- Next.js
- React
- TypeScript
- Tailwind CSS
